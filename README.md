# Hatch Releases

Public download surface for Hatch Desktop installers, release notes, and provenance manifests.

The application source repository is private. Public tags in this repository identify the corresponding private source commit without mirroring source history.

- [Latest release](https://github.com/keithhchen/hatch-releases/releases/latest)
- Every published installer is accompanied by its release classification and integrity evidence.
- The automatically generated source archives contain only this distribution repository, not the private application source.
